abstract = {Scientific input/output (I/O) optimizations require clear correctness evidence that application developers can review. We study deterministic export tests and scientist-vetted end-toend analyses within the Kokkos implementation of the Vector Particle-in-Cell (VPIC) application. These validations rely on different oracles and target different properties. This work in progress explores what kinds of correctness evidence should be provided alongside an application I/O optimization.},
